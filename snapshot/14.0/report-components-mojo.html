ivy:report-components

Full name:

com.axonivy.ivy.ci:project-build-plugin:14.0.2-SNAPSHOT:report-components

Description:

Reports re-usable components of a project to JSON.

Attributes:

  • Requires a Maven project to be executed.
  • Requires dependency resolution of artifacts in scope: compile.
  • The goal is thread-safe and supports parallel builds.
  • Since version: 14.0.2.

Optional Parameters

Name Type Since Description

Default: ${project.build.directory}/components
User Property: ivy.report.componentReportDir

Default: CONNECTOR
